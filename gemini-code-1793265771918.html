1. 피동 표현 (Passive Expression)

피동의 개념 주어가 다른 주체에 의해 동작을 당하거나 하게 되는 표현입니다. (반대: 능동)
피동 만드는 법
• 파생적 피동: 어근 + 피동 파생 접사(-이-, -히-, -리-, -기-) / '-되다'
• 통사적 피동: '-아/어지다', '-게 되다'
⚠️ 자주 틀리는 오개념
이중 피동 지양: 피동 표현을 두 번 중복해서 쓰면 잘못된 문장이 됩니다!
❌ 잊혀지다 (-히- + -어지다) ➔ ⭕ 잊히다 / 잊어지다
❌ 풀려지다 (-리- + -어지다) ➔ ⭕ 풀리다 / 풀어지다
❌ 취소되어지다 (-되- + -어지다) ➔ ⭕ 취소되다

2. 인용 표현 (Quotation Expression)

직접 인용 다른 사람의 말을 원래 형태 그대로 큰따옴표(" ")를 사용하여 가져오는 표현.
👉 인용 격조사: '라고' (예: 친구가 "같이 가자."라고 말했다.)
간접 인용 다른 사람의 말을 화자의 관점에서 형식에 맞추어 바꾸어 가져오는 표현.
👉 인용 격조사: '고' (예: 친구가 같이 가자고 말했다.)
⚠️ 간접 인용 변환 주의
• 어미 변환: 명령형 '-아라/어라' ➔ '-으라고' (예: "앉아라" ➔ 앉으라고)
• 지시어/대명사/시제 변환: '나' ➔ '자기/그', '지금' ➔ '그때', '오늘' ➔ '그날'
